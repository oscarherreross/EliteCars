# EliteCars_v2
Aplicación web JSP con servlet básico. Proyecto Maven con página de bienvenido (index.jsp) que enruta hacia servlet "Hola" en URL /hola.html mediante mapeo en web.xml. Incluye galería de imágenes de vehículos de lujo (Porsche, Mercedes, Tesla, McLaren, etc.). Estructura simple para aprender desarrollo web en Java con servidores de aplicación.
